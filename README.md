# Internship Project: DNA Sequence Classification Using Machine Learning

## Project Overview
This project focuses on DNA sequence classification using machine learning techniques. It uses DNA sequences from humans, chimpanzees, and dogs to explore preprocessing, feature extraction, model training, and performance evaluation.

## 🔗 Project Links

- 📄 **Research Paper:** [Click Here to Read the Research Paper](https://docs.google.com/document/d/1vQYts1r2z-XkYgq_a8eoYMrQ8LHgBgd4BYBSg4xCFdc/edit?usp=sharing)
- 📊 **Dataset:** [Click Here to Access the Kaggle Dataset](https://www.kaggle.com/datasets/nageshsingh/dna-sequence-dataset)
- 💻 **Jupyter Notebook:** `dna-sequence-internship.ipynb`

## 📁 Project Structure

- `Dataset/` — Dataset files
- `Report/` — Research paper and project report
- `dna-sequence-internship.ipynb` — Data preprocessing, model training, and evaluation

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

## 🎯 Objective
To investigate DNA sequence classification using machine learning algorithms and evaluate their performance on DNA sequences from different species.

## 🔬 Workflow
1. Data collection
2. Data preprocessing
3. DNA sequence encoding and feature extraction
4. Model training
5. Performance evaluation
6. Result analysis
