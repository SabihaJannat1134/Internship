## DNA Sequence Classification Using Machine Learning

This repository contains research work completed under the Internship Research Track, focusing on DNA sequence classification using machine learning techniques.

### 🎯 Research Objective

To investigate DNA sequence classification using machine learning algorithms and evaluate their performance on DNA sequences from humans, chimpanzees, and dogs.

### 🛠️ Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

### 🔬 Research Workflow

1. Data collection
2. Data preprocessing
3. DNA sequence encoding and feature extraction
4. Model training
5. Performance evaluation
6. Results analysis
